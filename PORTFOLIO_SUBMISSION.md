# Portfolio submission — AI Builder (Product)

**Project:** Academic Writing Copilot — AI-Powered Writing Feedback Assistant

**Product objective:** Help university students turn generic writing advice into prioritized, evidence-based revisions.

**Target users:** University students and English language learners.

**Applicant background:** English Language and Linguistics graduate study, research on technology-enhanced writing instruction, academic writing support, and coursework in Python/data analysis.

**MVP experience:** Paste a paragraph → receive structured feedback → revise → compare drafts → rate usefulness.

**Product rationale:** Prioritize explainability, user control, and actionable feedback over one-click rewriting. Separate local heuristic demonstration from model-powered results.

**Technical implementation:** Static HTML/CSS/JavaScript frontend, local heuristic fallback, optional Python FastAPI backend with server-side API credentials.

**Evaluation proposal:** Annotated sample set, issue precision, suggestion usefulness, latency, user feedback, and iterative prompt improvements. Evaluation is proposed, not completed.

**Known limitations:** Local heuristic mode is not AI; no persistent feedback storage; AI outputs may contain errors; not tested with real users yet.
